# Release Checklist

- [ ] Android project created and buildable.
- [ ] Native camera and microphone permissions verified.
- [ ] Two physical devices pass pairing and reconnect tests.
- [ ] RLS blocks cross-room access.
- [ ] Invitation expiry and revocation tested.
- [ ] Media expiry tested with app closed and offline.
- [ ] Screenshot disclaimer is accurate.
- [ ] Store policy review is completed for the selected distribution mode.
- [ ] Signing keys remain outside Git.
- [ ] Privacy policy and terms are linked.
- [ ] Production secrets are not in frontend bundles.
- [ ] Production tests and APK build pass.
